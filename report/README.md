# Results report (Overleaf project)

Upload this folder to Overleaf (New Project > Upload Project, as a zip) and compile `main.tex` with pdfLaTeX.

Everything in `figures/`, `tables/` and `numbers.tex` is generated by

```bash
python scripts/make_results_report.py
```

from the committed run outputs under `results/`. Do not edit those files by hand; rerun the script instead.
